# SynapseAI Backend

Backend API for SynapseAI - a location-based dating heatmap application.

## Description

FastAPI backend that provides APIs for tracking locations and generating heatmaps showing popular dating and social spots.

## Installation

```bash
poetry install
```

## Running

```bash
poetry run uvicorn main:app --reload
```

## Development

The backend uses FastAPI, SQLAlchemy, and PostgreSQL.
